# IT Park мэдээллийн сайт

Mobile-first танилцуулга болон PDF баримт бичгийн сан.

## Агуулга

- Танилцуулга: `documents/taniltsuulga.png`
- Дүрэм, журам: `documents/rendered/durem-juram/`
- Тайлан, төлөвлөгөө: `documents/rendered/tailan-tuluvluguu/`
- Хөдөлмөрийн дотоод журам: `documents/rendered/hudulmuriin-juram/`
- Ажил дүгнэх журам: `documents/rendered/ajil-dugneh/`
- Ёс зүйн дүрэм: `documents/rendered/yos-zui/`
- Мэдээ, мэдээлэл: `https://www.gov.mn/org/nitp/news`
- Санал хүсэлт: `support@itpark.mn`

Лого болон нүүр зургийг `assets/` хавтсанд байршуулсан. `site/` хавтсыг дурын статик веб серверээр ажиллуулна.

PDF эх файлуудыг нийтэд түгээхгүй. Сайт нь урьдчилан зураг болгосон хуудсуудыг зөвхөн унших байдлаар харуулна. Дэлгэцийн зураг авахыг техникийн хувьд бүрэн хориглох боломжгүй.
